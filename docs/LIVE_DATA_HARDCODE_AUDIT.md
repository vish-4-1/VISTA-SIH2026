**Date:** 2026-10-11
**Scope:** Eight dashboard pages, their API clients, and the authoritative FastAPI sources. Existing user changes were preserved; no commit, push, cleanup, VPN restart, or live workload was performed.

## Confirmed defects and replacements

- `vista-dashboard/src/components/views/TestbedView.jsx`: tunnel state was inferred from host-wide XFRM activity and collector health. It now uses `liveStatus.tunnel.state`; stale/unavailable results are distinguished, endpoint addresses are not filled from configured profile values, and events are explicitly host-wide.
- `vista-dashboard/src/components/views/OverviewView.jsx`: eBPF events could substitute for SA packet counts, missing probe count defaulted to five, host-wide XFRM events were labeled PC1↔PC2, and such events drove testbed animation. These were removed or relabeled.
- `vista-dashboard/src/components/views/TrafficAnalysisView.jsx` and `vista-dashboard/src/utils/apiClient.js`: fixed sample links and swallowed inventory failures were replaced with the actual backend sample inventory, explicit error/empty states, and file size display.
- `backend/main.py`: PCAP/CSV analysis responses now return the uploaded bytes' SHA-256 and size; generated reports include server `createdAt`.
- `vista-dashboard/src/components/views/AiAnalysisView.jsx`: model rows/classes come from the API; hardcoded global SHAP values and fixed reference-flow vectors were removed. A global table now requires a held-out evaluation status plus matching model ID, version, dataset hash, and feature values from the metrics API. With no uploaded capture, local-flow data and controls are unavailable.
- `vista-dashboard/src/components/views/SecurityAssessmentView.jsx`: unavailable audit requests no longer read as “no operational data”; unavailable rates do not render a zero-width score bar as a checked score.
- `backend/services/soc_service.py` and `vista-dashboard/src/components/views/ThreatIntelligenceView.jsx`: unrecognized attack labels no longer map to DOS; repository labels are shown as synthetic fixtures, the wrong source-string count was corrected, and no-feed status is explicit.
- `vista-dashboard/src/App.jsx` and `vista-dashboard/src/components/views/DatasetView.jsx`: active job state now survives tab changes; failed polling is visible; missing job progress is not substituted with 0%.
- `vista-dashboard/src/components/views/DatasetView.jsx`: repository samples with no `originType` are labeled “origin unknown”; the inspection drawer no longer asserts a fixed 18-feature count when its API response does not report one.
- `vista-ml/data/sample/vista_attack_sample_dataset.manifest.json` and `backend/services/dataset_service.py`: the legacy 20-row sample is explicitly `originType: unknown`, `provenanceStatus: incomplete`, and `UNVERIFIED`; the sample description no longer claims verified sessions without source PCAP/endpoint evidence. Unknown origin is not considered declared provenance.
- `vista-dashboard/src/components/views/ReportsView.jsx`: generation-only capability and server creation time are stated.

## Legitimate static and unavailable values

- Visual dimensions, Three.js positions/colors, status enums, supported configuration choices, ATT&CK technique mappings for explicitly registered labels, and explanatory UI copy remain static configuration.
- AI Analysis no longer supplies locally hardcoded reference flows. Per-flow explanation requires an uploaded flow record and the backend gate.
- No external threat-intelligence feed or IOC lookup is configured. The API exposes no report inventory. No operational security audit sessions or score are currently available. Ring-buffer loss is not reported in the current backend schema. Inference remains disabled for all loaded models and local/per-flow SHAP remains blocked.
- The former global SHAP registry values are suppressed: the available metrics API reports `NOT_VALIDATED`, and the saved summary is not linked to a provenance-complete held-out evaluation record. Dataset campaigns with evidence gaps remain `READY_FOR_REVIEW`, `BLOCKED`, or `UNVERIFIED` according to backend records; no new live collection was attempted.
